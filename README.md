# 坎公骑冠剑 · 日常挂机

> 个人自用存档，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 把对应游戏的日常任务自动化。
> 任务逻辑都写在 `assets` 里，欢迎直接 copy 改造。
> 模拟器仅在 Mumu 模拟器上测试过。

## 它能做什么

基于 `assets/interface.json` 配置，自动完成以下日常任务：

- **🎮 启动登录**：从桌面启动并登录游戏，停在游戏主页。需提前确认账号可以自动登录。
- **🛒 每日商店**：进入卡马逊商店自动购买，目前只买免费/金币商品，并领取订阅卡。
- **🏛️ 公会签到**：进入公会完成每日签到。
- **⚔️ 每日体力**：进入游玩指南，执行英雄传扫荡与裂痕扫荡。支持设置扫荡次数，并可勾选要刷的进化石 / 开花石 / 资源副本（可多选，建议每个类别只开一项）。
- **🏝️ 领取浮游城**：进入浮游城领取产出；默认主页是个人空间时会自动切换。
- **📋 领取任务**：领取每日任务奖励。

> 在 MaaFramework 启动器的任务列表中勾选 / 取消对应项，即可自定义要运行的任务。

## 使用前的游戏设置

- 模拟器分辨率建议 **1920 × 1080**
