# 坎公骑冠剑 · 日常挂机

> 个人自用存档，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 把对应游戏的日常任务自动化。
> 任务逻辑都写在 `assets` 里，欢迎直接 copy 改造。
> 有需要直接 copy 改造即可，不用问我，也无需另行告知。
> 模拟器仅在 Mumu 模拟器上测试过。

## 它能做什么

基于 `assets/interface.json` 配置，自动完成以下日常任务：

- **🎮 启动游戏**：启动游戏并回到游戏主界面。
- **📧 领取邮箱**：进入邮箱领取全部邮件奖励。
- **🤝 好友赠送**：进入好友界面，一键赠送好友礼物并领取。
- **🛒 每日商店**：进入卡马逊商店自动购买，目前只买免费/金币商品，并领取订阅卡。
- **🏛️ 公会签到**：进入公会完成每日签到。
- **⚔️ 刷体力 - 英雄传**：默认刷取英雄传，保留完整刷体力选项，可切换为裂隙。
- **⚔️ 刷体力 - 觉醒副本**：默认刷取资源/觉醒关卡中的觉醒副本。
- **⚔️ 刷体力 - 裂隙**：默认刷取裂隙，保留完整刷体力选项，可切换为英雄传。
- **🏝️ 领取浮游城**：进入浮游城领取产出；默认主页是个人空间时会自动切换。
- **🏟️ 圆形角斗场**：自动进入圆形角斗场并完成剩余次数战斗。
- **🔨 装备强化一次**：进入任务界面，完成每日任务「强化 1 次装备」，并返回主界面。
- **📋 领取任务**：领取每日任务奖励。
- **🎁 活动奖励**：依次领取邀请赛奖励、扭蛋机奖励和活动 3 奖励，可在 option 中分别设置跳过。

> 在 MaaFramework 启动器的任务列表中勾选 / 取消对应项，即可自定义要运行的任务。
